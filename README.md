# Pintas

Indonesia's stablecoin payment infrastructure — fast, cheap, and OJK-compliant.

Move money into and out of Indonesia at the speed of the internet.

## What is Pintas?

**Pintas** (Indonesian: "shortcut") is an API-first payment infrastructure layer for Indonesia. Pintas provides the programmable on/off-ramps, cross-border settlement, and compliance tooling that fintechs, remittance companies, and enterprises need to move money through the Indonesian corridor.

## Core Capabilities

- **IDR ↔ Stablecoin On/Off-Ramp** — Convert IDR to USDT/USDC via BI-FAST in <60 seconds
- **Cross-Border Settlement** — Send from Malaysia, Saudi Arabia, UAE, Singapore, US → Indonesia in <2 minutes
- **Institutional OTC Desk** — Block trades from IDR 75M, T+0 settlement
- **Developer API** — REST + WebSocket, SDKs for Node.js, Python, PHP, Go
- **Merchant Payments** — Accept crypto, settle in IDR, zero chargebacks
- **Treasury Management** — Multi-sig controls, spending limits, audit logs
- **White Label** — Launch a branded stablecoin wallet in 4–6 weeks
